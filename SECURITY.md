# Security and private data

Do not post credentials, saves, Ubisoft/Steam account identifiers, full memory
captures or unredacted diagnostic bundles in public issues. For a sensitive report,
use the repository's private vulnerability reporting feature when available, or
request a private contact route without disclosing the details publicly.

The release should contain only allowlisted original source/documentation,
licensed vendor source and the reviewed production ASI. Source control excludes
all build outputs and private state. No telemetry or account credentials are needed
by the mod. Compatibility and file ownership checks intentionally fail closed.
